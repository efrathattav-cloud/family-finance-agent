# סוכן כספי משפחתי (Family Finance Agent)

תכנון של סוכן AI שמנהל את המעקב הכספי של משק בית: קורא מיילים של קבלות וחיובים ואת קובץ התנועות מהבנק, מסווג כל תנועה, מוסיף אותה ל-Airtable בלי כפילויות, לומד מתיקונים ומתריע על חריגות מהתקציב.

מטלה לשיעור 6: AI Agents.

📄 **התכנון המלא נמצא ב-[SPEC.md](SPEC.md)**

## בקצרה

| מרכיב | בסוכן הזה |
|---|---|
| 🧠 LLM | Claude, מחליט על סיווג, כפילויות וחריגות |
| 🛠️ Tools | Gmail, Airtable, קבצים ו-bash לקריאת קובץ הבנק |
| 📓 Memory | Memory store עם מיפוי בתי עסק, תשלומים קבועים ולקחים |
| 🎯 Goal | הוראות בפורמט WHO, STEPS, RULES, DONE |
| 🔄 Loop | Managed Agents, מופעל כל בוקר, עם מגבלות של סבבים, עלות וזמן |
